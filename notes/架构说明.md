# hotspot-monitor 架构说明

> 版本：v1.0 ｜ 项目性质：5 天冲刺课程项目 ｜ 目标：70 分（能完整跑通核心链路）

## 一、一句话定义

基于 Hermes Agent + OpenCLI 的跨平台热点监控系统：用户用自然语言描述监控需求，AI 自动调用 OpenCLI 完成多平台热点抓取，再经 AI 分析后在网页看板展示。

## 二、系统数据流

```
用户自然语言需求
    ↓
【大脑】Hermes Agent
  - 理解需求、拆解任务、规划调用
  - 内置记忆系统（SQLite）
    ↓ 调用 CLI 命令
【手脚】OpenCLI
  - 内置网站适配器 + 浏览器桥（复用 Chrome 登录态）
  - 定时执行：opencli 各平台适配器 / hot-digest 插件
    ↓ 输出 JSON
【存储】SQLite（hotspots.db）
  - posts 表：platform / title / url / heat / fetched_at
    ↓
【分析】DeepSeek-V4-Flash API（主力）/ GLM-4.7-Flash（免费调试备胎）
  - 主题聚类、中文摘要、跨平台共振判断
    ↓
【呈现】Streamlit 网页看板
  - 今日热点列表（按平台过滤）+ AI 分析摘要
  - cron 定时驱动全流程
```

## 三、技术选型

| 层次 | 选型 | 理由 |
|---|---|---|
| 智能体框架 | Hermes Agent（Nous Research，MIT 开源） | 项目指定核心；支持 MCP、技能系统、SQLite 记忆；可接 OpenAI 兼容 API 或本地 Ollama |
| 抓取层 | OpenCLI（开源，Node.js） | 79+ 网站内置适配器；浏览器桥复用已登录 Chrome 会话，绕开登录与反爬；官方 hot-digest 插件一次聚合多平台热点 |
| 运行时模型 | DeepSeek-V4-Flash（主力）/ GLM-4.7-Flash（免费备胎） | 国内直连稳定、成本极低（约 ¥20/月）、1M 上下文 |
| 存储 | SQLite | 单用户单机零运维，Python 内置 sqlite3 库 |
| 看板 | Streamlit | 纯 Python 写网页，几十行出图表，新手友好 |
| 调度 | cron | 系统自带，零依赖 |
| 开发工具 | Trae 国内版（AI IDE）+ DeepSeek 网页版/Kimi（架构讨论） | 全部国内直连，不依赖海外网络 |

## 四、监控源策略（按网络环境分级）

- **主力源（国内直连、无需登录）**：HackerNews、GitHub Trending、掘金
- **加菜源（国内直连、需浏览器桥登录态）**：知乎、B站
- **本期放弃**：Twitter/X、Reddit（需代理，定时任务场景下引入不确定性；架构保留扩展能力，报告写入"未来工作"）

## 五、质量目标（70 分拆解）

1. 自然语言描述需求可被系统理解并触发抓取（Hermes 规划层）
2. ≥3 个平台热点数据自动入库（含失败容错：单平台失败不阻塞整体）
3. AI 分析产出可读的中文摘要（聚类 + 跨平台共振判断）
4. Streamlit 看板展示当日热点与分析
5. cron 定时无人值守全流程跑通
6. README + 架构图 + 演示录屏
