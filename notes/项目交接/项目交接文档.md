## 一、项目一句话定义

基于 Hermes Agent + OpenCLI 的跨平台热点监控系统：用户用自然语言描述监控需求，AI 自动调用 OpenCLI 完成多平台热点抓取，经 AI 分析后在 Streamlit 网页看板展示。5 天冲刺课程项目，目标 70 分（核心链路完整跑通）。

## 二、技术栈与架构（已定稿，不再变更）

```
自然语言需求 → Hermes Agent（规划/大脑）
  → OpenCLI（抓取/手脚，CLI 命令，输出 JSON）
  → SQLite hotspots.db（posts 表：platform/title/url/heat/fetched_at）
  → DeepSeek-V4-Flash API（分析：聚类+摘要+跨平台共振）
  → Streamlit 看板 + cron 定时
```

监控源：P0 = HackerNews / GitHub Trending / 掘金（无需登录）；P1 = 知乎 / B站（需浏览器桥登录态）；放弃 X/Reddit。
